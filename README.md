# Nextar Volley — démo

Démonstration de Nextar (détection et suivi des jeunes) réglée pour le volley-ball en salle, publiée sur
https://volleybase-demo.github.io/.

- Code : la même appli que la démo handball (dépôt HandBase, branche `clubs`), construite avec `VITE_SPORT=volley`.
- Données : base Supabase « Nextar-volley » (Paris), **entièrement fictives** (joueurs, clubs, observateurs inventés).
- Publication : onglet Actions → « Publier la démo » → Run workflow.
